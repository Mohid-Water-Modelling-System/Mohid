# Module Life

Module Life is a multiparameter biogeochemical module based on ERSEM. This is a more complex model compared to [Module WaterQuality](waterquality.md), which is able to simulate nutrients (nitrogen, phosphorus and silica biogeochemical cycles) along with several primary producers, secondary producers and decomposers in the water column. Variable N:P:C ratios in each type of organism’s are also computed.
