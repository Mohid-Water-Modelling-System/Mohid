# Module Jet

## Overview

Module JET, also known as MOHIDJET integral model, aims to simulate the initial dilution associated to outfalls jets. The model is used as an initial condition of [Lagrangian tracers module](lagrangian.md), used to simulate plume dispersion in the far field. Therefore, MOHIDJET is a very helpful tool to simulate the impact of outfalls water bodies integrating the near field (MOHIDJET) with the far field (MOHID). A Lagrangian approach was used in MOHIDJET similar to the one use in the JETLAG model (Lee and Cheung, 1990 [
