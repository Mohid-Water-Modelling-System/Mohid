## Short entries

### MOHID Time format

In MOHID data files, a certain date can be given by a keyword followed by a six number array, specifying, respectively, the year, month, day, hour, minute and seconds. For example and hipotetically if the user wishes to specify the date 19th of August, 2006, at 12h00, using keyword "DATE", this can be written in Mohid format as:

```
DATE                  : 2006 8 19 12 0 0
```
