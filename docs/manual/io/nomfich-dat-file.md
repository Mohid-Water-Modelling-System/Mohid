# Nomfich.dat file

A **nomfich.dat** file is a file commonly used in the MOHID Framework to indicate to a MOHID program the name and path of the input (instructions) file(s) and the path of the folder where the output files produced by the application will be written.

This **nomfich.dat** should be located in the program's working folder (or in the same folder where the executable file is placed).

The general structure of the **nomfich.dat** is as following:

```
IN_MODEL : ... (path to the input file)
ROOT_SRT : ... (path to the folder where output files are to appear)
```
