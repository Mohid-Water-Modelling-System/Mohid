### Configure SAMSUNG Printer

1. Add a new printer in printer wizard
2. Select "Network printer" radio button
3. Select "Connect to this printer" radio button and write "\\\\samsung.maretec.ist.utl.pt\\samsungSCX-4x21" in the text box
4. Ckick "Next" until finish th wizard.
5. Printer ready to use
