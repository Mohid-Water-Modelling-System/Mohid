# VPN

> **Archived page.** This content is kept for historical reference only. It may be out of date, incomplete or unrelated to the current MOHID documentation, and it is not maintained.

Para aceder a VPN são necessários fazer os seguintes passos:

WINDOWS

1. Ir a \\\\davinci\\Software\\VPN\_CISCO
2. Copiar o ficheiro para o vosso pc: Maretec-VPN.pcf
3. Ir a subpasta existente neste endereço referente à vossa versão de sistema operativo instalar os ficheiros .exe do vpn da cisco
4. Poderão ter de reiniciar após a instalação
5. Iniciar o software instalado
6. Na primeira vez que utilizam têm de fazer “Import” e escolher o ficheiro Maretec-VPN.pcf. Isto serve para terem o perfil Maretec carregad oe só é preciso fazer a primeira vez.
7. clickar em “Connect” e dar as credenciais.
