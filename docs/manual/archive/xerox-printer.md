## Installing Printer

1. Get the drivers in \\\\davinci\\Software\\ImpressoraXerox\_Drivers\\Windows 2K XP 03 Vista PS and depending on 32-bit or 64-bit choose the adequate folder and save the content to your computer (e.g. Softwate\\XeroxPrinterDriver),
2. From the control panelgo to"Printer and Faxes", delete the old printer,
3. In the same place, do an "Add printer",
4. Select "Local Printer Attached to This Computer". Uncheck "automatically detect my printer's drivers",
5. "Create a New Port"-->"Standard TCP/IP",
6. Printer IP --> See e-mail,
7. Select "Have disk ..." and select the .INF file in the folder in your computer where you copied the drivers (e.g. Softwate\\XeroxPrinterDriver),
8. Select the model XEROX 6400X PS
9. Say *ok* to everything,
10. That's it!

### Define Black and White as default color

In order to define black and white printing as default,

1. rigth click the printer and *Properties*
2. In *Advanced* tab -> click *Printing Defaults*
3. In *Color Options* tab -> check that radio button Black and White is selected. if not select it and press *OK* twice.

## Operating Printer

To operate printer in the corridor need to insert user code given by administrators to log in. After the operation log out.

### Printing from computer

After installing the drivers, may start printing.

The first time use, need to add to the printer configuration in your pc, the user code so that the printer acceps the printing:

1. From the control panel go to "Printer and Faxes",
2. In Xerox Printer, right-click it and select "Printer Properties",
3. Select "Configuration" tab,
4. Click "Accounting",
5. In Accounting box that appears in "Accounting System" select "Xerox Standard Accounting or Auditron",
6. In "Accounting Prompt", select "Do not prompt",
7. In "Default User" insert the user code,
8. In "Default Account Type" select "Default Group Account",

The above action allows the printing to send the user code to the printer and does not need to be done anymore.

In your pc, inside any document just have to select the Xerox 6400 printer.

### Copying

Go to the machine, log in and copy. After the operation log out.

### Scanning

Go to the machine and log in. Use "e-mail" to scan to e-mail (select from address book or add your own) or "Workflow Scanning" to scan to a folder and select the folder.

After the operation log out.

To access the folders content in your pc, in a web browser enter the printer ip and press enter. Then select "Scan" tab and select your folder where you can download your file. Remind to delete files after download because space is limited.

### Sending a fax

Or you have a paper document and go to the machine, log in and introduce the fax number Or you have a digital document in your computer -> Print -> Select the Xerox Printer -> Properties -> Paper/Output tab -> Job: Fax -> and then need to put fax number

After the operation log out.
