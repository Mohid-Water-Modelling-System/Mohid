# Google Earth

> **Archived page.** This content is kept for historical reference only. It may be out of date, incomplete or unrelated to the current MOHID documentation, and it is not maintained.

**Google Earth** is the openGL GIS client program that maps all the worlds orthophotomaps. It's an important tool to extract coastlines and other baseline georeferenced data in [kml](../linux/kml.md) format.

## Configure Google Earth

- From the *tools* menu, select *options*

- Select *decimal degrees*, then *apply* and click *ok*
