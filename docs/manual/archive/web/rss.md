# Rss

## How to use RSS reader with this [wiki](wiki.md)

Here's an example of how to include an Rss feed in mediawiki:

```
<rss>http://someplace.org/rss.xml%7Cshort%7Cdate%7Cmax=5</rss>
```

## How to install RSS reader in your own mediawiki

1. Download and unzip the [magpierss php program](http://sourceforge.net/project/showfiles.php?group_id=55691)into your wiki's */extensions* directory,
2. Copy the [mediaWiki RSS extension](http://meta.wikimedia.org/wiki/User:Alxndr/RSS) into your wiki's */extensions* directory,
3. Add the *extensions/rss.php* into your *LocaleSettings.php* file.

That should do it!
