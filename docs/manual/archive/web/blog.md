# Blog

> **Archived page.** This content is kept for historical reference only. It may be out of date, incomplete or unrelated to the current MOHID documentation, and it is not maintained.

**Blog** is a derived word from *web-log*, which stands as a web-based log. The interest is that it can be easily published, as well as can contain, besides text, multimedia rich content such as images, sound or films. A published **blog** typically provides an [rss](wiki-rss.md) feed, thus enabling broadcasting. An already notorious blogging site is [Blogger](http://www2.blogger.com).
