# Resize

**Resizing** a partition in a hard disk is a way to better manage a hard drive's resources. Several tools may be used for resizing.

## Linux

### QtParted

QtParted available in Knoppix distro.

## Windows

### Commercial

#### Norton Ghost

Is probably most popular commercial tool for resizing partitions.

### Free

#### Partition RESIZER

Is a free DOS resizer utility. It's best advised to be used from within a floppy boot disk or [USB boot drive](../../building/windows/usb-boot-drive.md). It does not resize an NTFS(WinXP,2k) partition.
