## Short entries

### Cat

**Cat** reads the input file and prints it to the stdout.

#### Syntax

```
> cat file
```

#### Example

```
> cat helloworld.txt
cat> Hello World!
```

#### External References

- [cat manpage](http://www.die.net/doc/linux/man/man1/cat.1.html).

### Cdrecord

**Cdrecord** is a command line utility in linux that burns an image to a writable cd.

#### Syntax

```
> sudo apt-get install cdrecord
> cdrecord --devices
> cdrecord dev='devices_result' -scanbus
> cdrecord -v -eject dev='devices_result':x,x,x debian.iso
```

#### See also

- [dd](dd.md)
- [mkisofs](mkisofs.md)

### Diff

**Diff** is a nice little utility that allows to check two files and see which lines are different.

#### Examples

This example will show the differences between *file1* and *file2*:

```
> diff file1 file2
```

This example will only output if the files are different:

```
> diff -q file1 file2
```

#### External References

- [diff man page](http://unixhelp.ed.ac.uk/CGI/man-cgi?diff)

### Linux network restart

To initialize the network in linux without having to boot the machine:

```
>/etc/init.d/network start
>/etc/init.d/network stop
>/etc/init.d/network restart
```

### Linux rdesktop

The **rdesktop** allows to connect remotely to windows systems:

```
> rdesktop -u Administrator -d MARETEC Einstein
```

To access to fedora@dual\_64 type.

$ vncviewer dual_64.maretec.ist.utl.pt:0

### Ln

Symbolic links are alias of a given library or binary file to another directory

#### Syntax

```
> ln -s $THERE/file $HERE/file
```

#### Examples

```
> ln -s $LOCATION/lib.so.0.0.0 lib.so
```

### Time

**Time** is a linux/unix utility that returns the time that a shell command took to be executed.

```
> time [options] commmand
```

#### Example

```
> time ls -l
```
