# Kino

Kino is a movie maker for linux. It works commonly from DV files but it can also import from other formats.

## Troubleshoots

T: *and the default preferences for video creation have not been specified* (when importing a media file)

S: Edit-->Preferences-->Defaults-->Normalisation=PAL

Check [this forum](http://ubuntuforums.org/archive/index.php/t-445466.html).
