# Date

**date** is a linux command returning the present date and time. In a dos box, current date and time are stored in environment variables.

## Linux

```
> date
> Thu May 17 13:52:35 WEST 2007
```

```
> date +%G%m%d
> 20070517
```

```
> date +%k:%M:%S
> 13:56:27
```

## DOS

```
$ echo %DATE%
$ 17-05-2007
```

```
$ echo %TIME%
$ 13:58:38,33
```
