# Firefox

> **Archived page.** This content is kept for historical reference only. It may be out of date, incomplete or unrelated to the current MOHID documentation, and it is not maintained.

**Firefox** is a popular open-source web-browser from the [Mozilla foundation](http://www.mozilla.org). It is remarkable for its extensions and plug-ins, all developed by the surrounding community.

## Some really useful extensions

- [Google Browser Sync](http://www.google.com/tools/firefox/browsersync/): developed by Google. This extension allows to synchronize the **Firefox** (bookmarks, history, cookies, opened tabs and saved passwords) by storing the configuration online in a Google account.

- [Google Gears](http://gears.google.com/): developed by Google. This extension allows dedicated web-apps to go offline. One example is [Google Reader](http://www.google.com/reader/view/). Now you can work offline with your web-app. And when you're done, you simply go online and synchronize.

- [del.icio.us](http://del.icio.us): This extension integrates seamlessly your bookmarks with your del.icio.us account. Works well for shortcuts too.

- [Greasemonkey](http://www.greasespot.net/): allows to run user scripts, little custom-made [javascripts](javascript.md) that run over the web-pages opened by **firefox**.

- [Google notebook](http://www.google.com/notebook/): developed by Google. Embeds seamlessly the notebook service provided by google for online storage of notes and text snippets. The only way of actually using this tool.
