# Tar

**tar** is a command line utility that archives files in linux.

## syntax

```
> tar tar-quive.tar
```

## Untar

```
> tar -zxvf tar-quive.tar.gz
```

## Examples

```
> tar -xvvf foo.tar
 extract foo.tar
```

```
> tar -xvvzf foo.tar.gz
 extract gzipped foo.tar.gz
```

```
> tar -cvvf foo.tar foo/
 tar contents of folder foo in foo.tar
```
