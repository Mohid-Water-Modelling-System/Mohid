# Baseline data

> **Archived page.** This content is kept for historical reference only. It may be out of date, incomplete or unrelated to the current MOHID documentation, and it is not maintained.

Baseline data is raw experimental data coming from diferent sources. In water quality modeling data splits into two families:

- point based data.
- gridded data.

The latter one usually comes from models, analyses, satellite data, whereas the former one is based on campaign samplings.
