# Email

> **Archived page.** This content is kept for historical reference only. It may be out of date, incomplete or unrelated to the current MOHID documentation, and it is not maintained.

How to configure an email sending service for Maretec such as [hudson](../tools/hudson.md).

```
server: smtp.gmail.com
port:  465 or 587
authentication?: yes
    user: mailing.maretec@gmail.com
    pass: the usual
    ssl?: yes
```
