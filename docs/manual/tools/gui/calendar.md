# Calendar

[Mohid](../../overview/mohid.md) (un)official [calendar](http://www.google.com/calendar).

Mohiders may subscribe to this calendar using their <goto>google account</goto>. Otherwise they can always create a <goto>google account</goto> in order to subscribe it. Some interesting features of <goto>google calendar</goto> are **free sms reminders**, email reminders and group meeting email invitations.
