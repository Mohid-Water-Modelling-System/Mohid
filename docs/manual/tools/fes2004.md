# Fes2004

Fes2004 is the tide level and harmonic predictor for tide of POC-LEGOS. Development credits go to Thierry Letellier and Florent Lyard.

An open discussion started around [this](http://www.mohid.com/hydrogroup/presentations/HG_060419_fes2004.ppt) presentation.

## Quick start

Get the [package](http://mohid.com/PublicData/products/Software/Mohid-Tide_v0.4.zip). Unpack it and read the readme-1st file for instructions. If you're working within MARETEC or HIDROMOD then map a network drive (say, *X:*) to *\\\\kepler\\DataCenter1\\DataCenter\\Modelos\_2(2)\\FES\\fes2004data*. If not, get the datasets [fes2004 here](ftp://ftp.legos.obs-mip.fr/pub/soa/maree/tide_model/global_solution/) and install them somewhere in your network with read permissions.

### Mohid-tide

Here's what the input file should look like (CAUTION: it's longitude latitude null!): CAUTION: The file MUST END with <end\_xyz>! Otherwise results will be erroneous. NO BLANK LINES ARE ALLOWED!

```
longitude latitude null
```

- Sample input:

```
<begin_xyz>
-61.410     -38.995   0.
-61.41      -39.00    0.
-61.41001   -38.99    0.
-61.41001   -38.7     0.
-61.41      -39.38    0.
-70.2       -56.2     0.
<end_xyz>
```

- The command line is :

```
mohid-tide X:\tide.nc input_mohid-tide.dat output.dat   0 2.08
```

In this example, the input file is called *input\_mohid-tide.dat*. The output file is called *output.dat*. The data file is called *tide.nc* and it's path is *X:\\*. The *0* and the *2.08* are respectively the time reference and the water level reference. Change all these parameters accordingly to your situation.

## Building fes2004 from scratch under windows

### Prerequisites

1. Get the [WinGSL](http://www6.in.tum.de/~kiss/WinGsl.htm) distribution. Unpack at least the dll.
2. Get the [netcdf](http://www.unidata.ucar.edu/downloads/netcdf/ftp/contrib/win32/netcdf-3.6.1-win32.zip) distribution. Unpack at least the dll.
3. Get the [fes2004 extraction/prediction sotware](ftp://ftp.legos.obs-mip.fr/pub/soa/maree/tide_model/global_solution/software/FES_extraction_prediction/).
4. Get the [data](ftp://ftp.legos.obs-mip.fr/pub/soa/maree/tide_model/global_solution/fes2004/tide/tide.fes2004.nc) file(~600MB) and rename it to tide.nc (or get it at *\\\\kepler\\DataCenter1\\DataCenter\\Modelos\_2(2)\\FES\\fes2004data*).

## fes2004 vs fes95

Essentially fes2004 contains 4 new relevant tidal components. And it supports higher resolution, allowing extraction of tidal gauges closer to the coast. These two reasons alone make it a very interesting asset to include in Mohid.
