# Intel array visualizer

Intel Array Visualizer allows to graphically explore the data in the arrays.

## How to install

1. Install VS Studio
2. Install Intel Array Visualizer
3. Install Intel Fortran

NOTE: the order is important. If Intel Fortran is already installed, then uninstall and reinstall it after installing Intel Array Visualizer.
