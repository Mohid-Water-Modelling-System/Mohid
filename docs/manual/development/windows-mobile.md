## PDA

### HTC P3300

#### [Optimus](http://www.optimus.pt/Particulares/ApoioAoCliente/ConfigTelemoveis/) GPRS connection

```
Menu Iniciar > Definições > Ligações > Ligações
Em O meu ISP, escolher Adicionar uma nova ligação de Modem:

Nome da ligação - Internet
Seleccionar Modem - Linha Móvel (GPRS)
Seguinte
Nome do ponto de acesso - internet
Nome de utilizador - Não preencher
Palavra Pase - Não preencher

Concluir
```

Then I still needed to change the connection type to **pap**

```
Start > Definições > Ligações > Definição GPRS > ligação PAP
concluir
```
