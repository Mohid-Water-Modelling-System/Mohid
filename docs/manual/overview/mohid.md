# MOHID

**MOHID** is the short name for *Modelo Hidrodinâmico* which means Hydrodynamic Model in Portuguese that was the original purpose of the model when it was created back in 1985. MOHID Water Modelling System is a modular finite volumes water modelling system written in ANSI [FORTRAN 95](http://en.wikipedia.org/wiki/FORTRAN) using an object oriented programming philosophy, integrating diverse numerical models and supporting graphical user interfaces that manage all the pre- and post-processing. It is an integrated modelling tool able to simulate physical and biogeochemical processes in the water column as well as in the sediments, and is also able to simulate the coupling between these two domains and the latter with the atmosphere.
