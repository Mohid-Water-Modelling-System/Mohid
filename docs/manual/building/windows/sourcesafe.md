# SourceSafe

[Microsoft Source Safe](http://en.wikipedia.org/wiki/Visual_SourceSafe) is the software used for [source control](http://en.wikipedia.org/wiki/Source_control). Other known version managers are [cvs](http://en.wikipedia.org/wiki/Concurrent_Versions_System) or [svn](http://en.wikipedia.org/wiki/Subversion_%28software%29). [SourceOffSite (sos)](http://www.sourcegear.com/sos/index.html) is the software of choice when working from an outside network.
