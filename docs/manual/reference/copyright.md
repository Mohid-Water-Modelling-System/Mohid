# Copyright

To copyright a program every file containing source code must include the following information:

- One line to give the program's name and an idea of what it does.

- Copyright (C) yyyy name of author

Mohid source files should include this couple of lines:

---

MOHID Water Modelling System.
Copyright (C) 1985, 1998, 2002, 2006. MARETEC, Instituto Superior Técnico, Technical University of Lisbon.

---
