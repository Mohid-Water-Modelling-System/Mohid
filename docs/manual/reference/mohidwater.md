# MohidWater

MohidWater is the software that runs the Mohid Water modeling tool. Designed in an Object Oriented fashion, it's composed of integrated modules. Here's MohidWater [modular structure](../water/modules/modules.md).

## Installing MohidWater

1. Download the Mohid Water Modelling System [here](http://www.mohid.com/MembersArea/index.asp). Just remember to register first.
2. Install it by running the installation software (win XP).

### Linux platforms

If you're using Linux, you can send an e-mail to **general@mohid.com** asking for source files package. Refer to [\*NIX\_platforms](../archive/linux/nix-platforms.md) on how to build it and install it.

## How to setup a simulation

To setup a simulation one should follow the right [methodology](../water/model-setup-methodology.md):

- [Model setup methodology](../water/model-setup-methodology.md)

You will probably need to use the following tools:

- [Mohid GIS](../tools/gui/mohid-gis.md), to create bathymetries, tidal gauges and other horizontal fields.
- [Mohid GUI](../tools/gui/mohid-gui.md), to graphically create and configure simulations and runs.

Also you will need to configure an extensive list of configuration files:

- [/Simulation](simulation.md)
