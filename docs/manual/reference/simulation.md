# /Simulation

## /GeneralData

The /GeneralData is the default folder where to keep model's input baseline data such as bathymetries, S, T, Tide and waterproperties initialization. Usually you'll copy here the files created from [Mohid GIS](../tools/gui/mohid-gis.md).

### /exe

Folder containing the [Nomfich.dat](../io/nomfich-dat-file.md) in use. Its the [MohidWater](mohidwater.md) executable home folder.

### /figures

Default folder where to put images generated by [Mohid PostProcessor](../tools/gui/mohid-postprocessor.md) and [Mohid GIS](../tools/gui/mohid-gis.md)

### /res

Mohid model outputs will be placed here in [HDF5](../tools/hdf5.md) format. To visualize and browse content you should use:

- [Mohid GIS](../tools/gui/mohid-gis.md)
- [Mohid PostProcessor](../tools/gui/mohid-postprocessor.md)
- [HDF5 viewer](http://hdf.ncsa.uiuc.edu/hdf-java-html/hdfview/)

To extract and export their content you should refer to

- [Mohid GIS](../tools/gui/mohid-gis.md)
- [Mohid PostProcessor](../tools/gui/mohid-postprocessor.md)
- [HDF5Extractor](../tools/hdf5extractor.md)
