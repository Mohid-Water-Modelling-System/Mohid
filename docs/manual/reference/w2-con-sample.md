# W2 con sample

This is the list of known keywords that need to be changed based on the Beliche ( *\\\\Datacenter\\Albufeiras\_Eutrofizacao\\ComoFazer\\2.CorreCe-Qual\\ExemploFeito\_Beliche\\1.SimulacaoZero\\AdaptedToW2con*) runs.

## Useful recommendations

1. Use the *Cin\_br1.npt*, *Tin\_br1.npt* and *Qin\_br1.npt* files from the Beliche run and replicate them for every branch.
2. Use the *shd.npt* and *wsc.npt* files generated by the w2i geometry software.
3. Then, edit the *wsc.npt* file and alter the ending date to 1000. (days).
4. Alter the *w2\_con.npt* from the Beliche run accordingly to your watershed geometry.
