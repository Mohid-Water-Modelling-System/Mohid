# Virtualization

Virtualization in Maretec was used in two systems: Xen and VMWare

## Xen

It was installed on AMD Opteron 2352 a Xen server (Suse distribution) and initially were created amon others 3 VM: web server, ftp server and openDAP server. In 2011 web server migated to the cloud and two other remained.

See [Xen](../archive/linux/xen.md) page for specifications.

## VMWare

It will be installed a CISCO server with VMWare ESXi 5.0 and will be implemented 3 VM: ftp server and openDAP server (same as before) and the duplicate of physical domain controller server.

See [VMWare](../archive/linux/vmware.md) page for specifications.
