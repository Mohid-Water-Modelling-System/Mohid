# Templates

Templates allow to include pre-set wiki text inside an article. It can be useful to insert complex [html](../archive/web/html.md) data.

## List of templates

- Template:div - Inserts an html block inside a <div/> tag.
- Template:center - Centers html code.
- Template:img - Inserts an image from an url.
- Template:video - Inserts a google video.
- Template:vimeo - Inserts a vimeo video.
- Template:youtube - Inserts a youtube video.
