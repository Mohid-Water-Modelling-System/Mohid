# Valida4D

Valida (from validation) 4D (space + time).

The goal of the tool was to allow the MOHID user to compare the model results with every type of observed data: • ADCP; • CTD; • Remote grid data • Along track observations (satellite, ships, gliders) • Etc.

[https://github.com/Mohid-Water-Modelling-System/Mohid/tree/master/Software/SmallTools/Valida4D](https://github.com/Mohid-Water-Modelling-System/Mohid/tree/master/Software/SmallTools/Valida4D)

## Input file (XXXX.dat)

```
PROPERTY_NAME            : ... (name of the property whose values are being interpolated)
PROPERTY_UNITS           : ... (units of property whose values are being interpolated)
```
