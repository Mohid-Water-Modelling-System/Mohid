### Choose a semi-implicit approach

#### WaterProperties\_x.dat

For each property is possible to define a explicit or semi-implicit approach to compute the horizontal transport. By default is assumed a explicit one (ADVECTION\_H\_IMP\_EXP : 1 ).

```
    <beginproperty>
     ADVECTION_H_IMP_EXP      : 0
    <endproperty>
```

### Coordinates type

In Mohid the following coordinate types can be used:

> -   **1** - Geographic coordinates
> -   **2** - UTM coordinates
> -   **3** - Portuguese military coordinates
> -   **4** - Simplified geographic coordinates: in Degrees
> -   **5** - Metric coordinates referred to the origin of the grid
> -   **6** - Circular coordinates
> -   **7** - NRLD - Dutch metric coordinate system

### Wind surface stress

Wind stress is calculated according to a quadratic friction law:

$\overrightarrow{{\tau_w}} = C_D \cdot \rho_a \cdot \overrightarrow{W}|\overrightarrow{W}|$

where $C_D$ is a drag coefficient that is function of the wind speed, $\rho_{a}$ is air density and $\overrightarrow{W}$ is the wind speed at a height of 10 m over the sea surface.
